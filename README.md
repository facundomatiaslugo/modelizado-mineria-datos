# Modelizado y Mineria de Datos

Construcción paso a paso del pipeline de datos.

## Estructura
- data/raw: datos originales
- data/interim: datos parcialmente limpios
- data/processed: datos listos para modelar
- notebooks: Jupyter notebooks
- src: código fuente
- tests: pruebas

## Entorno
- Python 3.12
- Virtualenv en .venv
- JupyterLab
- PostgreSQL (Docker)
